# Android release owner gate

The native shell may be built/tested automatically.

Before first Google Play application creation, owner must approve:

1. final package ID (current provisional candidate: `com.riseshineevolve.gentlesteps`);
2. final app icon / splash approval (a reversible purple/gold/cream internal-test candidate is generated automatically);
3. store listing name if different from `24 Gentle Steps to Christmas`;
4. monetization model if any;
5. Play App Signing / signing-key handling;
6. final privacy/Data Safety declarations.

These choices are intentionally not inferred from the book or from other RSE apps.
