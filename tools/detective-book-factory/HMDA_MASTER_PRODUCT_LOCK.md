## Product positioning

**Happy Makers Detective Academy: The Mystery of Room Zero**

- Primary reader: children roughly **8–12**
- Format: **8.5 x 11 inch**, grayscale paperback
- Target feel: a modern, screen-free detective game / dossier adventure
- Target length: roughly **130–145 pages**, allowed to move when final map spreads and print QA require it
- Language sequence: **English master first, Polish second from the same canonical source**
- Product category: real CASES and fair-play deduction, not a generic activity book or disconnected worksheet collection
- Tone: adventurous, witty, supportive, clever, energetic, never babyish
- Reader remains the detective. Happy Makers support the investigation but never steal the final deduction.

## Market-differentiation lock

The book must stand out through:

- one sustained large mystery rather than a bag of unrelated puzzles
- premium visual coherence
- fair logic with no required guessing
- strong difficulty progression
- recurring evidence that changes meaning later
- humor that comes from character and situation rather than random jokes
- satisfying page-turn / callback moments
- child agency and accusation before reveal
- solutions that explain *why*, not merely give an answer
- a final payoff that rewards remembering and revisiting earlier cases

A technically valid puzzle is not enough. Every mission must also serve pacing, character,
world-building, the Room Zero mystery, or a deliberate breathing beat.

## Canonical reader loop

The core case loop is:

**CASE → context → possibilities → clues/puzzle → evidence → deduction → reader accusation → reveal/reasoning → small Room Zero clue → Happy Makers reaction → evolving hypothesis**

The book-level loop is:

**solve → notice → remember → reinterpret → revisit → connect → Room Zero payoff**

Cases may vary in page count and puzzle family. Do not force every case into the same template
if that weakens pacing.

## The big case

The 30 missions are one connected investigation.

Locked meta arc:

- recurring plain `0`
- old Academy connection
- Grandma Bibi's incomplete memory
- `RULE 0 FIRST`
- `THE ANSWER IS IN WHAT YOU LEAVE EMPTY`
- fourteen solved spatial maps become evidence again
- empty ROOM initials spell `CHECK THE OLD MAP`
- old map reveals the sealed training room
- Rule Zero is restored:
  `ZERO ASSUMPTIONS. NOTICE FIRST. THEORIZE SECOND.`
- boss map supplies the earned final access coordinate
- Room Zero reveals that the reader is the missing / next detective
- after-credits hook: `CASE 001 // STILL OPEN`

The recurring `THE BIG CASE / EVIDENCE WALL` beats are structural, not decorative.
They exist to keep the macro mystery alive and to make solved material accumulate into a real case file.

## Happy Makers role lock

Happy Makers are recurring investigative companions with fixed jobs and distinct voices.

- **Luli — Lead Clue Analyst / Logic Guardian**
  Protects facts from unsupported theories, spots contradictions, uses dry concise humor.
- **Dilo — Code & Tech Agent**
  Owns codes, numbers, devices and extremely confident questionable theories. His ideas must survive evidence.
- **Alio — Field Agent**
  Owns routes, maps, physical exploration and bold hypotheses. Often proposes tunnels, helmets or dramatic shortcuts.
- **Nini — People & Courage Specialist**
  Helps nervous witnesses and readers, gives the gentlest first nudge, normalizes being stuck without becoming sugary.
- **Mimi — Case Captain**
  Turns chaos into a plan, manages evidence and pacing, practical but not boring.
- **Grandma Bibi — Adventure Keeper**
  Holds fragments of Academy history, odd keys and old memories. She may unlock context but may **never solve the case for the reader**.

Dialogue rules:

- short, natural, useful
- every exchange should advance clue interpretation, pacing, emotion or characterization
- no generic mascot chatter
- no overexplaining the lesson
- humor is a reward, not filler
- child detective has the decisive moment

## Difficulty and logic diversity

Difficulty rises through reasoning depth, clue interaction and memory load, not simply by adding more characters.

The spatial source bank may share the Shigai BASIC end rule accepted for production-source purposes,
but the final HMDA experience must vary deduction personality across the set.

Meaningful variety includes:

- exact row / column
- room membership
- corner / outer wall
- diagonal
- Manhattan distance
- relative directions
- person-to-person relationships
- person-to-object relationships
- order / nth position
- either/or
- same-room dependencies
- chained deductions
- elimination

Do not attempt to use every mechanic in every puzzle. Each case should have a dominant logic personality.

The original raw-source planning target was Rookie / Field Agent / Master progression. The **final locked source manifest** wins over any older provisional difficulty label.

## Shigai boundary

Shigai BASIC is a **verified spatial-deduction source engine**, not the product designer.

Allowed Shigai role:

- generate / preserve logic geometry
- provide source maps, clues, verified placement and solution
- provide difficulty / deduction evidence where useful

Not Shigai's role:

- final Happy Makers story
- final room names
- final cast names
- Room Zero meta-game
- final RSE book page design
- final humor
- final KDP layout

The approved visual direction is **HYBRID MAP FACTORY**:

**original verified Shigai map art + geometry**
+
**RSE/HMDA framing, final ROOM/ZONE naming, narrative, solution layer and meta-game**

Do not redraw strong Shigai furniture/geometry merely because a code-drawn version is easier.
Code-drawn maps remain a logic-safe fallback / diagnostic representation, not the preferred final aesthetic.

## Hint and solution lock

Every mission uses a **three-level Hint Vault**:

1. gentle orientation
2. stronger logical nudge
3. near-solve clue that still lets the reader make the final move

Solutions must:

- preserve fair-play logic
- explain the deduction path
- distinguish fact from inference
- avoid production terminology
- never rely on a hidden answer not available to the reader

## Safety / story content

Preferred mystery stakes:

- missing / swapped objects
- harmless sabotage
- mislabeled items
- secret messages
- access / route / timing mysteries
- family-safe misunderstandings

Avoid making the product depend on violent crime, adult danger, or material that undercuts the playful detective tone.

## Reusable Book Factory lock

Book 1 must not become a one-off manual artifact.

Durable architecture:

**content YAML → validated source puzzle / normalized geometry → visual skin → page-family renderer → hints / solutions → locale → KDP preflight → PDF**

Future books should mostly require:

- new case/content YAML
- new verified source modules/assets
- new volume-level meta spine
- optional new page-family modules only when genuinely needed

Do not fork the renderer for each volume.

GitHub is the durable technical source of truth.
Canva is a finishing layer only, never the only editable master.

## Do-not-regress checklist

A future agent must not:

- turn the book into 30 unrelated worksheets
- make Happy Makers decorative mascots
- make an adult/character solve the final deduction for the child
- reopen the Room Zero twist without owner approval
- replace fair-play deduction with guessing
- flatten difficulty into repeated versions of the same logic
- use raw Shigai production language in reader-facing copy
- promote stale QA answers over the final spatial manifest
- silently redraw source geometry
- make Canva the source of truth
- create a separate Polish content fork
- publish automatically
