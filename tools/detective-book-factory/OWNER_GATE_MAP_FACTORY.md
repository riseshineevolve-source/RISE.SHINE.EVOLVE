# Happy Makers Detective Academy — Map Factory Owner Gate

Status: **READY TO PRESENT, NOT YET APPROVED**
Date: 2026-09-18

## Why this gate exists

The English Book 1 master is reproducible and the editorial preflight is green. The remaining release-critical production choice is the visual system for the 15 locked spatial cases.

Do **not** scale all 15 maps until this gate is approved.

## Three required pilot cases

The canonical Map Factory contract requires these three pilots because together they test the full range:

| Case | Role | Grid | What it proves |
|---|---|---:|---|
| HMDA_02 | early Rookie | 6x6 | clarity, friendliness, low cognitive load |
| HMDA_13 | advanced Field Agent | 7x7 | dense evidence hierarchy and room/zone legibility |
| HMDA_29 | Room Zero boss | 9x9 | maximum map density and end-game scalability |

## Non-negotiable logic lock

Visual approval must not change:
- grid geometry,
- source partition topology,
- blocked/occupiable semantics,
- clue-dependent furniture/object locations,
- source character placements,
- source clue meaning,
- verified answer identity or coordinate.

If any of these changes, the puzzle must be revalidated and the visual change cannot be treated as cosmetic.

## Intended production direction

The current canonical direction is **HYBRID MAP FACTORY**:

- retain the verified original Shigai map geometry/art as the central visual layer,
- apply RSE/HMDA framing, typography, ROOM/ZONE labels, evidence/dossier chrome and solution treatment around it,
- keep the map large enough for pencil use,
- preserve explicit coordinates,
- keep puzzle maps answer-free,
- show placements/reasoning only in solution treatment,
- use grayscale / light paper field suitable for KDP print.

The spatial case is a paired experience:
1. **WITNESS BOARD** — story, objective, Happy Makers banter and all fair-play clues.
2. **LIVE CASE MAP** — large hybrid map and verdict field.

This prevents the map from being crushed into a worksheet layout.

## Owner review checklist

Approve the system only if all three pilots satisfy all of the following:

### 1. Premium-book feel
- feels like a detective case file, not a worksheet,
- Happy Makers identity is visible without overpowering the puzzle,
- visual hierarchy remains coherent across 6x6, 7x7 and 9x9.

### 2. Print readability
- coordinates, room labels and character/prop symbols remain readable at real 8.5 x 11 print size,
- no dense black field that makes pencil work unpleasant,
- no text shrunk merely to fit.

### 3. Puzzle integrity
- no answer marker or meta-room emphasis on the puzzle page,
- ROOM versus ZONE distinction is understandable,
- nothing visual accidentally makes the Room Zero carrier special before Case 26.

### 4. Story integration
- Witness Board and Live Case Map feel like one investigation,
- clues are readable without competing with the map,
- the reader is led to solve, not guess.

### 5. Boss scalability
- HMDA_29 still feels intentional at 9x9,
- density does not collapse labels, icons or coordinate rails.

## Approval outcomes

Only three useful decisions exist:

- **APPROVE SYSTEM** — scale the exact visual language mechanically to all 15 locked modules.
- **APPROVE WITH SMALL FIXES** — fix only the listed presentation issues, rerender the three pilots, then scale.
- **REJECT SYSTEM** — do not touch all 15; revise the pilot visual system first.

## After approval

The automation may:
1. scale the locked visual system to all 15 spatial modules,
2. validate geometry + unique answer + ROOM/ZONE meta carrier,
3. attach puzzle/solution assets to the canonical English master,
4. run strict release preflight,
5. freeze the English source only after all 15 pass.

KDP publication remains a separate owner gate.
