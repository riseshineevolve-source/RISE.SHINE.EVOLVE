## Implementation boundaries

- Modern setting copy cannot change object occupancy, room geometry, gender-dependent clue identity, relative direction, distance, numeric order, source answer or target relationship.
- Give the guest/keeper a role before using their name. Numeric witness IDs are independent of letter-number grid coordinates.
- Where the physical output only identifies the other person in a room, the verdict identifies that contact. Do not imply this alone proves who swapped, stole, accepted or caused something.
- Show what the story names: photos, scraps, footprints, route map, overlay layers, bag items, ticket, receipt, tag, badge, screen or note. Text lists alone do not satisfy a visual-evidence promise.
- Keep completed spatial positions available for Case 26. The hidden initial is documentation here, never a label printed as an early answer on the puzzle page.
- All thirty post-case beats above have a specific carrier or interpretive event. Case 18 is a rejected lead; Case 29 adds access evidence; Case 30 explains cause. A giant 0 is not a substitute for those distinct jobs.
